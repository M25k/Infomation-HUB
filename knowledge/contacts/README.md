# Kontakte

Zweck: Kontaktlisten zu Organisationen und Personen, mit denen Northdocks zusammenarbeitet oder im Gespräch ist (Kunden, Partner, Förderkonsortien, Multiplikatoren). Grundlage für Angebote, Anträge und Nachverfolgung. Pflege über den Bot „Northdocks Wissen“.

- [organizations.md](organizations.md): Organisationen, plus Tabelle „Kunden aus Mailakte Silas“
- [people.md](people.md): Personen

## Format

Je Eintrag ein Abschnitt `## Name` mit diesen Feldern:

- **Ort/Land** (Organisationen) bzw. **Organisation** (Personen, als Link auf organizations.md)
- **Typ** bzw. **Rolle**
- **Ansprechpartner** (Organisationen, als Link auf people.md) bzw. **Kontaktweg** (nur Kanal, z. B. „E-Mail (Gmail Joachim)“)
- **Themen**
- **Bezug** (Links auf knowledge/*.md, Asana)
- **Freigabe**
- **Historie:** Zeilen `TT.MM.JJJJ · Kanal · Inhalt`, neueste zuerst

## Regeln

- Keine Mailadressen, keine Telefonnummern, keine privaten Anschriften, keine Zugangsdaten.
- **Freigabe** ist einer von drei Werten: **nennbar** (darf in Angeboten und Anträgen namentlich genannt werden), **nur intern**, **Freigabe fehlt** (Default für neue Einträge).
- Vor Namensnennung externer Personen gilt die Namensregel in [document-rules.md](../document-rules.md) (Abschnitt „Referenzen“).
- Volumen und Rechnungen nicht hier pflegen, sondern in [accounting.md](../accounting.md) (FreeAgent gilt).
