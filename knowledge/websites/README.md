# Website-Wissen

Interne Grundlage für **Inhalte und Struktur** der Northdocks-Sites.  
Nicht die Live-Seite ersetzen: Live bleibt Quelle für Layout; **Claims und Verbote** kommen aus diesem Ordner plus [claims.md](../claims.md).

Beim Ändern einer Website zuerst:

1. [`.cursor/skills/website-content/SKILL.md`](../../.cursor/skills/website-content/SKILL.md)
2. [_shared.md](_shared.md)
3. Die Datei der betroffenen Domain (unten)

Nur Stufe **öffentlich** aus claims.md auf die Site. Intern Belegtes (Eignung, >100 Kunden, Umsatz, TMA-Vertrag) nicht ungefragt auf die Website kopieren.
